# 🚀 Landing Page Website

This is my **first project using Next.js** — a responsive and dynamic landing page website.

## 🛠️ Tech Stack

- **Framework**: [Next.js](https://nextjs.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **UI Components**: [shadcn/ui](https://ui.shadcn.com/)

## ✨ Features

- Clean, responsive design
- Component-based structure with shadcn/ui
- Tailwind utility classes for fast styling
- Built for easy scaling and customization
